# بخش ۳ — کاربران و نقش‌ها، قفل، رمز، خروج

شناسه‌ها: `MT-USR-*` — زمان: حدود ۱ ساعت. پیش‌نیاز: کاربران و داکتران ساخته شده (`MT-INS-15`، `MT-INS-16`).

## ج) جمع‌بندی بخش ۳

اگر هر یک از این‌ها «رد» شد، **بحرانی** است:
* نقشی که نباید، گزارش مالی/تنظیمات/کاربران را ببیند یا تغییر دهد.
* مدیر بتواند رمز یا نقش مالک را عوض کند.
* منشی بتواند فاکتور را باطل کند.
* قفل صفحه اطلاعات بیمار را نشان بدهد.

برای ادامه: [بخش ۴: یک بیمار از ورود تا آخر](04-patient-diary.md).
