# بخش ۵ — جستجو، Ctrl+K، ادغام، بایگانی/حذف، ورود/خروج فایل، فهرست بلند

شناسه‌ها: `MT-SRC-*` — زمان: ۱ ساعت. پیش‌نیاز: بیماران P1..P10 (بخش ۴) + بیمار تکراری «مریم کریمی» (MT-PAT-09).

### MT-SRC-06 — ادغام دو پروندهٔ تکراری
دو «مریم کریمی»: اصلی P1 (پر)، تکراری T (پروندهٔ جدید که در MT-PAT-09 ساختید). برای تست کامل، **روی T** یک نوبت، یک پیوست، یک یادداشت و یک بیماری در «سوابق پزشکی» ثبت کنید (T: «سوابق»: «آسم = بله»).
| # | کار | باید ببینید | نتیجه |
|---|---|---|---|
| ۱ | در پروندهٔ T ← «کارهای بیشتر» ← «ادغام با پرونده دیگر» | جستجوی بیمار مقصد («جستجوی بیمار مقصد…») | ☐ ☐ |
| ۲ | خودش را انتخاب کنید | «یک پرونده را نمی‌توان با خودش ادغام کرد.» | ☐ ☐ |
| ۳ | P1 را انتخاب کنید | دو پرونده **کنار هم**؛ «پرونده‌ی اصلی (می‌ماند)» = P1، «این پرونده (غیرفعال می‌شود)» = T؛ هشدار «پرونده‌ی «T» غیرفعال می‌شود و نوبت‌ها، فاکتورها و سوابق آن به «P1» می‌رود. این کار برگشت‌پذیر نیست.» | ☐ ☐ |
| ۴ | دکمه «ادغام» | **غیرفعال** تا تیک «مطمئنم؛ پرونده‌ی n ادغام شود» را بزنید | ☐ ☐ |
| ۵ | ادغام | «پرونده‌ها ادغام شدند.» | ☐ ☐ |
| ۶ | P1 را ببینید | نوبت/پیوست/یادداشت T حالا اینجاست؛ سوابق پزشکی: «آسم = بله» از T اضافه شده (پاسخ محتاط‌تر می‌ماند: «بله» بر «نه»)؛ اگر هر دو جواب داده بودند، «بله» می‌ماند | ☐ ☐ |
| ۷ | T را ببینید | غیرفعال؛ ادغام دوباره: «این پرونده با پرونده دیگری ادغام شده است؛ پرونده اصلی را انتخاب کنید.» | ☐ ☐ |
| ۸ | جستجو در لیست و Ctrl+K | T (ادغام‌شده) در جستجوی ادغام بعدی پیشنهاد نمی‌شود؛ ممکن است هنوز در جستجوی عادی با نشان «غیرفعال» باشد (طراحی عمدی، `PA-24`) | ☐ ☐ |
| ۹ | مالی P1 | فاکتورها و پرداخت‌های T به P1 آمده؛ جمع‌ها درست (اگر T پولی نداشت، عددهای 04b عوض نمی‌شود) | ☐ ☐ |
| ۱۰ | Audit | ردیف ادغام | ☐ ☐ |

> **هشدار:** ادغام برگشت ندارد. اگر عددهای 04b را حفظ می‌کنید، T را **بدون** فاکتور/پرداخت بسازید.

## ج) ورود و خروج فایل

### MT-SRC-07 — خروجی Excel/CSV
(مالک) `بیماران ← «⋯» ← خروجی اکسل/CSV`: «فایل Excel ذخیره شد: … (n بیمار)»؛ فایل را در Excel باز کنید: ستون‌ها با عنوان فارسی، نام‌های فارسی/پشتو درست و خوانا، تلفن با صفر ابتدایی. دوباره خروجی بگیرید: فایل قبلی **رونویسی نمی‌شود** (پسوند `-2`). ☐ ☐

### MT-SRC-08 — ورود از فایل (فهرست بلند ۲۵۰ بیمار)
در PowerShell (نه در برنامه) این فایل را بسازید:
```powershell
$rows = 1..250 | ForEach-Object { [pscustomobject]@{ 'نام کامل'="تست بیمار $_"; 'نام پدر'="پدر $_"; 'شماره تماس'=('0790'+('{0:D6}' -f $_)) } }
$rows | Export-Csv "$env:USERPROFILE\Desktop\patients250.csv" -NoTypeInformation -Encoding UTF8
```
| # | کار | باید ببینید | نتیجه |
|---|---|---|---|
| ۱ | `بیماران ← «⋯» ← ورود از فایل` ← «انتخاب فایل CSV» | «تطبیق ستون‌ها»: برای هر ستون فایل، فیلد بیمار (نام، نام پدر، تلفن…) یا «نادیده بگیر»؛ «ردیف اول عنوان ستون‌ها است» | ☐ ☐ |
| ۲ | بدون ستون «نام» | «یک ستون باید به «نام و تخلص» نگاشت شود.» | ☐ ☐ |
| ۳ | یک فیلد را دو بار نگاشت | «هر فیلد را فقط یک‌بار و ستون موجود را انتخاب کنید.» | ☐ ☐ |
| ۴ | درست کنید ← «پیش‌نمایش نتیجه» | «کل سطرها ۲۵۰، قابل ورود ۲۵۰، رد شده ۰» | ☐ ☐ |
| ۵ | «وارد کردن بیماران» | «۲۵۰ بیمار با موفقیت وارد شد.» | ☐ ☐ |
| ۶ | فایل با ۳ سطر بد (تلفن `12`، نام خالی) | «رد شده ۳» و «خطاهای سطرها» با شمارهٔ سطر | ☐ ☐ |
| ۷ | فایل `.xls` یا `.txt` | «فقط فایل‌های .xlsx و .csv پشتیبانی می‌شوند…» | ☐ ☐ |
| ۸ | فایل Excel با چند برگه | انتخاب «برگه (Sheet)» | ☐ ☐ |
| ۹ | وارد کردن دوباره همان فایل | هشدار/ردّ تکراری‌ها (ببینید چه شد؛ یادداشت کنید) | ☐ ☐ |
