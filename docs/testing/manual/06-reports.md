# بخش ۶ — گزارش‌ها (هر ۲۶ گزارش)، Excel، چاپ/PDF، داشبورد، اعلان‌ها

شناسه‌ها: `MT-REP-*` — زمان: ۱٫۵ ساعت.
**ترتیب:** این بخش را **بعد از 04b و قبل از 05 و 07** انجام دهید (تا عددها دست‌نخورده باشد). گزارش‌های انبار بعد از بخش ۷ بررسی می‌شود (MT-REP-30..).
با `owner.test` یا `acc.test` کار کنید. بازهٔ همهٔ گزارش‌ها: **امروز**.

صفحه: `گزارش‌ها`. چپ/راست: «فهرست گزارش‌ها» با «دسته» (مالی، بالینی، انبار) و «پرکاربردها» (۱۶ گزارش) + دکمه «همهٔ گزارش‌ها» (هر ۲۶). بازه: «بازهٔ سریع» (امروز، ۷ روز اخیر، این ماه، ماه گذشته، امسال) یا «از تاریخ / تا تاریخ». فیلتر «داکتر» و «خدمت» روی گزارش‌های مربوط. دکمه‌ها «خروجی Excel» و «چاپ / PDF». زیر جدول «جمع».

## ب) گزارش‌های مالی (بازه: امروز) — عددها از جدول 04b

ستون‌ها: تاریخ، تعداد پرداخت، صورتحساب‌شده، دریافتی، برگشتی، خالص.
**باید ببینید:** یک ردیف (امروز): تعداد پرداخت **۱۱**، صورتحساب‌شده **۷۶٬۴۰۰**، دریافتی **۲۸٬۱۵۰**، برگشتی **۲۵۰**، خالص **۲۷٬۹۰۰**؛ جمع همین. (فاکتور باطل P11 و «از اعتبار» حساب نمی‌شود.) ☐ ☐

### MT-REP-02 — درآمد ماهانه

### MT-REP-03 — پرداخت‌ها
۱۱ ردیف (تاریخ، شماره رسید، بیمار، روش، مبلغ)، جمع **۲۸٬۱۵۰**. پیش‌پرداخت P3 (۳٬۰۰۰) هست؛ «از اعتبار» و بازپرداخت نیست. روش‌ها: نقد ۸ ردیف، حواله بانکی ۲، پول موبایلی ۱. ☐ ☐

### MT-REP-04 — طلب‌های باز (بدون بازه)
۳ ردیف به ترتیب مانده: عبدالله نیازی **۲۵٬۰۰۰** (۱ فاکتور)، مریم کریمی **۱۸٬۵۰۰** (۲ فاکتور؛ «سررسید بعدی» امروز)، حاجی غلام سخی نوری **۵٬۰۰۰** (۱). جمع صورتحساب‌ها ۴، جمع باقی‌مانده **۴۸٬۵۰۰**. با «مانده طلب از بیماران» داشبورد و «جمع بدهی» بدهکاران **یکی** باشد. ☐ ☐
> این گزارش «تا امروز» است؛ بازه‌ای ندارد (`FR-07`).

### MT-REP-05 — تخفیف‌ها

## ج) گزارش‌های بالینی

### MT-REP-13 — بیماران جدید
ردیف برای هر بیمار ثبت‌شدهٔ امروز (با تاریخ ثبت، شماره، نام، تلفن، منبع). **تعداد = بیمارانی که شما ساخته‌اید** (۱۲ اگر P1..P10 + T + P11). ستون «منبع» فقط برای P1 «آشنا یا خانواده». سطر «جمع» = تعداد. ☐ ☐

### MT-REP-14 — درمان‌های انجام‌شده
هر درمان تمام‌شده با تاریخ، بیمار، دندان، خدمت، داکتر، ارزش: **۱۲** ردیف (P1: ۵، P2: ۲، P3: ۲، P4: ۱، P5: ۱، P6: ۱) — ارتودنسی در جریان است و فقط اگر برنامه آن را هم نشان بدهد اضافه می‌شود (یادداشت کنید). فیلتر داکتر/خدمت. ☐ ☐

### MT-REP-15 — اقدامات (به تفکیک خدمت)
تعداد انجام هر خدمت؛ برای هر خدمت با گزارش ۱۴ جور باشد (مثلاً فیشورسیلانت = ۲). ☐ ☐

### MT-REP-16 — وضعیت دندان‌ها
شمارش یافته‌هایی که ثبت کردید (پوسیدگی ۳۶ = ۱، غایب ۳۷ = ۱، …). یافته‌ای که «از چارت برداشته» شد نباید شمرده شود. ☐ ☐

### MT-REP-17 — فعالیت داکترها
برای هر داکتر: نوبت‌ها، تکمیل‌شده، نیامده، لغوشده، درمان‌ها. با تقویم و صف مقایسه کنید (مثلاً «نیامده» = تعداد نوبت‌های نیامده در MT-PAT-20). ☐ ☐

### MT-REP-18 — پیگیری‌ها
پیگیری‌های ثبت‌شده (P1 «۶ ماه بعد»، P2 فراخوان جرم‌گیری) با نوع، وضعیت («نیاز به تماس»/«تماس گرفته شد»/…)، آخرین تماس. ☐ ☐

### MT-REP-19 — فهرست یادآوری بیماران (تا تاریخ)
بیمارانی که تا آن تاریخ باید تماس بگیرند. «تا تاریخ» را به ۱ سال بعد ببرید ← P1 و P2 می‌آیند. ☐ ☐

### MT-REP-20 — منبع معرفی بیماران
یک ردیف: «آشنا یا خانواده» ۱ (و «نامشخص» برای باقی اگر نشان دهد). ☐ ☐
