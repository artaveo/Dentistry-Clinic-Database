# واژه‌نامه و «برنامه چطور فکر می‌کند»

## الف) برنامه چطور فکر می‌کند (یک صفحه)

```text
کلینیک  ──(یک کامپیوتر، یک دیتابیس رمزشده، یک مجوز)
  │
  ├─ کاربر (نقش: مالک / مدیر / پذیرش / داکتر / حسابدار / دستیار)
  ├─ داکتر + یونیت (+ برنامه کاری، استراحت، رخصتی)
  ├─ تعرفه: دسته ← خدمت ← نوع (قیمت را کلینیک می‌گذارد)
  │
  └─ بیمار  (شماره P-000123، نام دلخواه به هر زبان)
       ├─ سوابق پزشکی (چک‌لیست) ← هشدار بالای پرونده و هنگام نسخه
       ├─ نوبت ← صف امروز ← «در درمان» ← «تکمیل ویزیت» ← پیگیری/تماس
       ├─ چارت دندان:  «وضعیت فعلی»  |  «پلان»  |  «انجام شد»
       │        پلان درمان ← آیتم (خدمت + دندان + قیمت + جلسه‌ها)
       │        درمان انجام‌شده  ═══►  «آماده فاکتور»
       ├─ یادداشت بالینی (امضا ← قفل)، نسخه، رضایت‌نامه، پیوست/X-ray
       └─ پول:
            فاکتور ← (تخفیف) ← قابل پرداخت
               ├─ پرداخت (رسید RC) جزئی یا کامل، پیش‌پرداخت = «اعتبار»
               ├─ اقساط (مجموع = مانده؛ پرداخت‌ها به‌ترتیب قسط‌ها را پر می‌کنند)
               ├─ بازپرداخت (RV) / یادداشت اعتبار (CN) / ابطال: همیشه با دلیل
               └─ مانده = بدهی ← فهرست بدهکاران، صورت‌حساب
       همه چیز ← صندوق (نقد) ← بستن صندوق ← گزارش‌ها ← پشتیبان
```

**قواعد ذهنی:**
۱. **فاکتور مثل کاغذ مهر خورده است:** صادر شد، دیگر ویرایش نمی‌شود. اشتباه = ابطال یا یادداشت اعتبار.
۲. **حذف نداریم، بایگانی داریم.** بیمار/جنس/داکتر با سابقه حذف نمی‌شود، غیرفعال می‌شود.
۳. **پول:** بدهی = مجموع «قابل پرداخت» − (پرداخت − بازپرداخت). صندوق فقط «نقد» را می‌شمارد. «اعتبار بیمار» پیش‌پرداختی است که هنوز روی فاکتور نرفته.
۴. **درمان چندجلسه‌ای (ارتودنسی):** بعد از اولین جلسه می‌توان کل مبلغ را فاکتور کرد و با اقساط گرفت؛ جلسه‌ها ادامه می‌یابد.
۵. **زمان:** تاریخ پرداخت همیشه «امروز» است؛ نوبت فقط برای آینده؛ جلسهٔ درمان می‌تواند گذشته باشد.
۶. **امنیت:** دیتابیس رمز؛ کلید در ویندوز؛ **Recovery Key** تنها راه باز کردن روی کامپیوتر جدید.
۷. **اینترنت** فقط برای مجوز/آپدیت/ابر؛ کار روزانه بدون آن.
۸. **مجوز** فقط تعداد کامپیوتر را محدود می‌کند؛ پایان مجوز = فقط‌خواندنی (دیدن، چاپ، Export، پشتیبان همیشه آزاد).

## ب) واژه‌نامه

| واژه (در برنامه) | معنی |
|---|---|
| یونیت | صندلی/اتاق درمان |
| داکتر | پزشک دندان |
| نوبت | وقت از پیش گرفته‌شده |
| صف امروز | بیماران امروز در ۴ ستون: منتظر آمدن، در انتظار، در درمان، تمام‌شده |
| بیمار بدون نوبت (Walk-in) | آمده بدون وقت قبلی |
| لیست تماس / فراخوان (Recall) | بیمارانی که باید دوباره آمد؛ «تکرارشونده» (مثلاً جرم‌گیری هر ۶ ماه) یا «یک‌بار» |
| پیگیری بعدی | تاریخ تماس مجدد که هنگام تکمیل ویزیت می‌گذارید |
| هشدار پزشکی / بنر | بالای پرونده: حساسیت، دیابت، حاملگی… |
| سوابق پزشکی | چک‌لیست ۳۴ سؤال |
| چارت دندان | نمودار دندان‌ها؛ نماها: عمومی، ارتودنسی، ایمپلنت، پروتز، پریو |
| وضعیت موجود / برنامه‌ریزی‌شده / در حال انجام / تمام‌شده | رنگ‌های چارت |
| FDI | شماره‌گذاری بین‌المللی (۱۱–۴۸)؛ پیش‌فرض برنامه «ربعی ۱ تا ۸» با شیری I–V |
| سطح دندان | M مزیال، D دیستال، O جونده، B باکال، L لینگوال |
| پلان درمان | فهرست کارهای پیشنهادی با قیمت؛ وضعیت: پیشنهادی ← پذیرفته‌شده ← در جریان ← تمام‌شده / لغوشده |
| آیتم / درمان | یک خدمت روی دندان |
| جلسه | یک مراجعه برای یک درمان چندجلسه‌ای («جلسه ۲ از ۳») |
| مرحله | ترتیب انجام در پلان (۱ تا ۵) |
| آماده فاکتور | درمان تمام‌شده که هنوز فاکتور نشده |
| برآورد (`TP-…`) | سند چاپی پلان با قیمت و اعتبار |
| فاکتور (`INV-…`) | سند مالی غیرقابل‌ویرایش |
| رسید (`RC-…`) | سند پرداخت؛ چاپ دوباره = «کپی» |
| پیش‌پرداخت / اعتبار (`CU-…`) | پولی که بیمار از پیش داده و هنوز روی فاکتور نرفته |
| بازپرداخت (`RV-…`) | پس دادن پول (با دلیل) |
| یادداشت اعتبار (`CN-…`) | کم کردن مبلغ فاکتور بعد از صدور (با دلیل) |
| ابطال | باطل کردن فاکتور بدون پرداخت (با دلیل)؛ پرداخت‌دار: اول بازپرداخت |
| قسط | بخشی از مانده فاکتور با تاریخ سررسید؛ وضعیت: در انتظار، بخشی پرداخت، پرداخت شد، گذشته |
| بدهکار | بیمار با مانده مثبت |
| کمیسیون | سهم داکتر؛ مبنا: «درمان فاکتورشده» یا «پرداخت دریافت‌شده» |
| صندوق / بستن صندوق | شمارش نقد پایان روز و مقایسه با «مورد انتظار» |
| مورد انتظار | نقد دریافتی − بازپرداخت نقد − هزینه از صندوق |
| لات / FEFO | دستهٔ جنس انبار؛ اول از زودمنقضی‌تر برداشته می‌شود |
| کار لابراتوار | سفارش تاج/بریج/دندان مصنوعی به لابراتوار با وضعیت‌ها |
| Audit / گزارش رویدادها | ثبت فقط‌خواندنی هر کار حساس |
| مجوز / License | اجازهٔ استفاده برای یک کلینیک؛ تعداد کامپیوتر طبق پلن |
| فقط‌خواندنی | حالت بدون مجوز: دیدن و چاپ و پشتیبان بله، تغییر نه |
| Recovery Key | کلید ۳۶ حرفی برای بازیابی روی کامپیوتر جدید یا فراموشی رمز مالک |
| حالت امن | صفحهٔ بازیابی وقتی کلینیک باز نمی‌شود |
| قرنطینه (`quarantine`) | پوشه‌ای که فایل خراب را بدون حذف نگه می‌دارد |
| سرور کلینیک / کلاینت | کامپیوتر نگه‌دارندهٔ داده / کامپیوترهای متصل |
| کد اتصال | کد ۶ رقمی ۱۰ دقیقه‌ای برای افزودن کامپیوتر |
| کد پیگیری | ۶ حرفی روی خطا؛ برای پشتیبانی |
| SmartScreen | هشدار ویندوز برای برنامهٔ بدون امضا |
| حالت کارایی | خاموش‌کردن افکت‌ها برای کامپیوتر ضعیف |
