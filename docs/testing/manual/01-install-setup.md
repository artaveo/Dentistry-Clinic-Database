### MT-INS-12 — ساعت کامپیوتر و مجوز (فقط بخوانید؛ **امتحان نکنید**)

برنامه در مجوز «بیشترین زمانِ دیده‌شده» را به یاد می‌سپارد. اگر ساعت ویندوز **بیش از ۲۴ ساعت عقب** برود، مجوز «ساعت کامپیوتر عقب رفته» می‌شود و برنامه فقط‌خواندنی. جلو بردن ساعت هم ثبت می‌شود؛ بعد از برگرداندن ساعت همین مشکل پیش می‌آید. **هیچ‌وقت روی کامپیوتر اصلی ساعت را عوض نکنید.** (VM: بخش MT-PAT-71)
