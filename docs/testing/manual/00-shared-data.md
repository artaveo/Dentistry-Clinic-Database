# داده‌های نمونهٔ مشترک

همه‌ی بخش‌های راهنما از همین جدول‌ها استفاده می‌کنند. **عیناً وارد کنید** تا عددهای «باید ببینید» جور درآید. همه چیز ساختگی است.

## ۱. کلینیک اصلی تست

| مورد | مقدار |
|---|---|
| نام کلینیک | `کلینیک نمونهٔ تست` |
| ولایت / ولسوالی | کابل / (هر ولسوالی کابل) |
| آدرس | `کابل، کارته چهار، سرک دوم` |
| شماره تماس | `0700 123 456` |
| زبان | فارسی (دری) |
| تقویم | هجری شمسی |
| نوع کلینیک | **چند داکتر** (برای تست کمیسیون و گزارش داکتر لازم است) |
| ساعات کاری | شنبه تا پنج‌شنبه، ۸:۰۰ ق.ظ تا ۴:۰۰ ب.ظ؛ جمعه بسته |

## ۲. کاربران (رمزها فقط برای تست)

حداقل رمز ۸ حرف است. نام کاربری فقط حروف انگلیسی، عدد و `.` `_` `-` (۳ تا ۳۲ حرف).

| نقش (در برنامه) | نام کاربری | نام نمایشی | رمز | کجا ساخته می‌شود |
|---|---|---|---|---|
| مالک | `owner.test` | `مالک نمونه` | `Owner#2026` | ویزارد |
| مدیر | `admin.test` | `مدیر نمونه` | `Test#12345` | تنظیمات ← کاربران |
| پذیرش | `reception.test` | `منشی نمونه` | `Test#12345` | » |
| داکتر | `dr1.test` | `داکتر نمونه اول` | `Test#12345` | » |
| داکتر | `dr2.test` | `داکتر نمونه دوم` | `Test#12345` | » |
| حسابدار | `acc.test` | `حسابدار نمونه` | `Test#12345` | » |
| دستیار | `asst.test` | `دستیار نمونه` | `Test#12345` | » |

## ۷. چند اصطلاح که زیاد می‌شنوید

* **یونیت** = صندلی/اتاق درمان (در رابط «یونیت» نوشته می‌شود؛ قبلاً «چوکی» بود).
* **داکتر** (نه «دکتر») — واژهٔ رسمی رابط.
* **صف امروز** = بیمارانی که امروز در کلینیک‌اند.
* **لیست تماس** = بیمارانی که باید دوباره با آن‌ها تماس گرفت.
