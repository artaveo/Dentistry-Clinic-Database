# بخش ۱۶ — تصویر بیمار و داکتر، صفحه داکتر، تصویر یونیت (OF-049، OF-050، OF-051)

شناسه‌ها: `MT-AVA-*` — زمان: ۴۵ دقیقه. با `owner.test`، و یک بار با `reception.test`.
پیش از شروع: یک عکس صورت (jpg یا png) روی دسکتاپ بگذارید، و یک فایل غیرعکس (مثلاً یک فایل متنی که نامش را `x.png` کرده‌اید).

## ب) عکس واقعی بیمار

| ۱ | پرونده بیمار ← روی تصویر کوچک کنار نام کلیک (یا «…» ← «گذاشتن عکس»، یا دکمه دوربین زیر تصویر بزرگ در «نمای کلی») | پنجره «عکس بیمار» | ☐ ☐ |

| ۵ | دوباره پنجره ← فایل `x.png` (غیرعکس) | «این فایل عکس قابل خواندن نیست…»؛ چیزی ذخیره نمی‌شود | ☐ ☐ |

| ۸ | دوربین را در Windows ببندید یا اجازه ندهید | «وب‌کم در دسترس نیست…»؛ انتخاب فایل هنوز کار می‌کند | ☐ ☐ |
| ۹ | «حذف عکس» | «عکس حذف شد…»؛ تصویر پیش‌فرض برمی‌گردد | ☐ ☐ |

| ۱۱ | با کاربری که «ویرایش بیماران» ندارد | تصویر هست ولی دکمه تغییر عکس نیست | ☐ ☐ |

## ج) داکتران و صفحه داکتر

### MT-AVA-04 — فهرست و صفحه داکتر
| # | کار | باید ببینید | نتیجه |
|---|---|---|---|
| ۱ | تنظیمات ← داکتران و یونیت‌ها | هر ردیف: تصویر، نام، تخصص، برنامه، وضعیت؛ **دکمه‌های «ویرایش» و «برنامه کاری» در فهرست نیست** | ☐ ☐ |

| ۳ | روی ردیف کلیک کنید (یا Tab و Enter) | صفحه داکتر: تصویر بزرگ، نام، تخصص، جواز، حساب کاربری، رنگ؛ دکمه‌های «ویرایش»، «برنامه کاری»، «گذاشتن عکس» | ☐ ☐ |
| ۴ | «ویرایش» ← جنسیت «زن» ← ذخیره | تصویر داکتر زن (قد کامل) در صفحه؛ تصویر کوچک در فهرست، سرستون تقویم، صف | ☐ ☐ |
| ۵ | زبانه «نمای کلی» | نوار هفته (ساعت هر روز، تعطیل/رخصتی، شمار نوبت‌ها)، نوبت‌های امروز، نوبت‌های بعدی، رخصتی‌های پیش رو | ☐ ☐ |
| ۶ | زبانه «برنامه کاری» | ساعت‌ها و استراحت‌های هر روز؛ دکمه «برنامه کاری» همان پنجره قبلی را باز می‌کند | ☐ ☐ |
| ۷ | زبانه «یونیت‌های مجاز» | یونیت‌های مجاز با تصویر؛ اگر هیچ‌کدام انتخاب نشده: «همه یونیت‌ها» | ☐ ☐ |
| ۸ | زبانه «آمار» | درصد نوبت‌های تکمیل‌شده ۹۰ روز گذشته بر اساس دسته خدمات؛ اگر نیست: پیام «… نیست» | ☐ ☐ |
| ۹ | «گذاشتن عکس» برای داکتر | عکس در صفحه، فهرست، تقویم و صف | ☐ ☐ |
| ۱۰ | «داکتران» (بازگشت) | فهرست، از بالای صفحه | ☐ ☐ |
