# بخش ۱۴ — هر فهرست و هر تنظیم: افزودن، ویرایش، غیرفعال، فعال دوباره، حذف، تکراری، ورودی بد، اثر روی صفحه‌های دیگر؛ و چاپ همه‌چیز

شناسه‌ها: `MT-CRD-*` — زمان: ۳ ساعت. با `owner.test`.
**الگوی تست برای هر فهرست** (همه جدول‌های زیر از همین الگو پیروی می‌کنند):

> ۱) افزودن  ۲) ویرایش  ۳) **تکراری** (همان نام/کد)  ۴) **ورودی بد** (خالی، خیلی بلند ۳۰۰ حرف، علائم `< >`، فقط عدد)  ۵) **غیرفعال** (و اینکه کجا دیگر نمایش داده نمی‌شود)  ۶) **فعال دوباره**  ۷) **حذف** (اگر هست؛ و اینکه با سابقه حذف نمی‌شود)  ۸) **اثر روی صفحه‌های دیگر** (فرم‌های انتخاب، گزارش‌ها، چاپ‌های قبلی)  ۹) `Esc` وسط فرم: «تغییرات ذخیره نشده».
