# بخش ۷ — انبار، تأمین‌کننده، لابراتوار، خاموش کردن ماژول‌ها

شناسه‌ها: `MT-STK-*` — زمان: ۱٫۵ ساعت. با `owner.test` یا `acc.test`.
**ترتیب:** بعد از بخش ۶ (گزارش‌های مالی). منوی `انبار` چهار زبانه + تنظیمات دارد: **موجودی | خریدها | تأمین‌کنندگان و لابراتوارها | کارهای لابراتوار | تنظیمات انبار**.

> مقدار: در ظاهر عدد معمولی بنویسید (مثلاً `20`). داخل برنامه ×۱۰۰ ذخیره می‌شود؛ ایراد نیست.
