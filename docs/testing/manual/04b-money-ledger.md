# بخش ۴b — مثال مالی کامل با عددهای دقیق

شناسه‌ها: `MT-MON-*` — زمان: ۲ تا ۳ ساعت. پیش‌نیاز: بخش ۴ (بیمارها و درمان‌ها). همه عددها **افغانی**.
این بخش مهم‌ترین بخش راهنماست: اگر یک عدد غلط باشد، **بحرانی** است.

> قاعده: همهٔ پرداخت‌ها با تاریخ **امروز** ثبت می‌شوند، پس همهٔ عددهای گزارش امروز یک‌جا جمع می‌شود. **قبل از شروع، هیچ پرداخت، فاکتور یا هزینهٔ دیگری ثبت نکنید** (کلینیک تازه باشد). نکتهٔ حسابداری: دقیقاً همین ردیف‌ها را به همین ترتیب وارد کنید.
> با `owner.test` یا `acc.test` کار کنید (منشی قیمت را نمی‌تواند عوض کند و فاکتور را باطل نمی‌کند).
