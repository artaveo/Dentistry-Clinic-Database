# بخش ۱۰ — تاب‌آوری: قطع ناگهانی، حالت امن، گزارش خطا، صفحه کوچک، تم، RTL

شناسه‌ها: `MT-RES-*` — زمان: ۱٫۵ ساعت. **قبل از هر تست خراب‌کننده پشتیبان بگیرید** و تست‌های خراب‌کننده را فقط روی کلینیک آزمایشی انجام دهید.

## ج) صفحه کوچک، تم، زبان

### MT-RES-07 — اندازه‌های صفحه
پنجرهٔ برنامه را به ابعاد زیر برسانید (رزولوشن ویندوز را عوض کنید: `Settings ← System ← Display` یا پنجره را هم‌اندازه کنید؛ برنامه حداقل ۸۰۰×۶۰۰ دارد). برای هر اندازه این صفحه‌ها را ببینید: داشبورد، فهرست بیماران، پروفایل (چارت)، تقویم، صف، فاکتور، گزارش‌ها، تنظیمات ← خدمات.
| # | اندازه | باید ببینید | نتیجه |
|---|---|---|---|
| ۱ | **۱۳۶۶×۷۶۸** (لپ‌تاپ رایج) | صفحه بدون اسکرول افقی؛ نوار کناری/بالا جا می‌شود؛ جدول خدمات ستون قیمت دارد | ☐ ☐ |
| ۲ | **۱۲۸۰×۷۲۰** | همین؛ چارت دندان بدون اسکرول صفحه | ☐ ☐ |
| ۳ | **۱۴۴۰×۹۰۰ و ۱۹۲۰×۱۰۸۰** | چیدمان کش نمی‌آید/خالی نمی‌ماند | ☐ ☐ |
| ۴ | پنجرهٔ کوچک ۸۰۰×۶۰۰ | کار می‌کند؛ ستون‌های کم‌اهمیت پنهان می‌شود؛ هیچ دکمه‌ای زیر لبه گم نمی‌شود | ☐ ☐ |
| ۵ | مقیاس ویندوز **۱۲۵٪ و ۱۵۰٪** | متن بریده نمی‌شود؛ دیالوگ‌ها از صفحه بیرون نمی‌زنند؛ دکمهٔ «ذخیره» پایین دیالوگ دیده می‌شود | ☐ ☐ |
| ۶ | دیالوگ بلند (ثبت بیمار، فاکتور) در ارتفاع ۷۲۰ | نوار «ذخیره/لغو» چسبنده؛ بقیه اسکرول می‌شود | ☐ ☐ |
| ۷ | پیمایش با **فقط کیبورد** (Tab، Enter، Esc) | هر دکمه فوکوس واضح دارد؛ «پرش به محتوا» | ☐ ☐ |

### MT-RES-09 — ضعف کامپیوتر
(اگر کامپیوتر ۴ گیگ RAM دارید) برنامه را با ۲۵۰ بیمار باز کنید: زمان باز شدن تا صفحه ورود < حدود ۳ ثانیه؛ جستجو و باز کردن پرونده روان. ☐ ☐

### MT-RES-10 — بدون اینترنت
کابل/Wi-Fi را قطع کنید. تمام کارهای روزانه (بیمار، نوبت، چارت، فاکتور، پرداخت، گزارش، چاپ، پشتیبان محلی) **بدون خطا** کار می‌کند. فقط «فعال‌سازی/بررسی مجوز» و «آپدیت» و «ابر» به اینترنت نیاز دارند و پیام مناسب می‌دهند، نه خطای ترسناک. ☐ ☐
