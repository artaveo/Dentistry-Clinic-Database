# جدول پوشش — هر صفحه، زبانه، دکمهٔ مهم و تنظیم ← کدام سناریو آن را آزمایش می‌کند

(از `Shell.tsx`، `Settings.tsx` و همهٔ فایل‌های `ui/src/pages/**` استخراج شد.) اگر چیزی در برنامه دیدید که اینجا نیست، یک «پیشنهاد» بنویسید.
