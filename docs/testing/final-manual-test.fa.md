# تست دستی نهایی — Artaveo Dental (v0.12.1)

این تنها تست دستی محصول است (تصمیم مالک). برای هر مورد: **کار** ← **باید ببینید** ← اگر نشد، گزارش بدهید (شمارهٔ مورد + عکس صفحه + «گزارش خطا» از سیستم). علامت ☐ را بعد از قبول شدن بزنید.

**قبل از شروع:** یک کامپیوتر ویندوز واقعی (ترجیحاً دو تا: x64 و ARM64)، یک فلش، یک پوشهٔ Google Drive/OneDrive، یک چاپگر A4 و در صورت امکان حرارتی. فایل‌ها از [Releases](https://github.com/artaveo/Dentistry-Clinic-Database/releases): `ArtaveoDental-Setup-<معماری>.exe` (و `-offline`).
