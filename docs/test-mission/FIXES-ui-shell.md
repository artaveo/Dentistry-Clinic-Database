## نیاز به تصمیم مالک
1. **R-15:** لابراتوار به ماژول انبار وصل است؛ کلینیکی که انبار نمی‌خواهد ولی لابراتوار دارد نمی‌تواند. جداکردن یک تغییر محصول است.
2. **U-24:** قیمت‌گذاری گروهی (ضریب) برای ۴۱ خدمتِ بی‌قیمت در نصب تازه — قابلیت جدید.
3. **U-16:** آیا دکتر باید «مالی» و «انبار» را در منو ببیند؟ UI فقط از مجوزهای Core پیروی می‌کند.
4. **U-30:** گروه «پیشرفته‌ی جمع‌شده» برای شبکه/مجوز/رویدادها انجام نشد؛ اگر می‌خواهید، بگویید.
