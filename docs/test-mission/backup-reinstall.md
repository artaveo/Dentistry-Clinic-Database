## ادامه (جلسه‌ی دوم)
- نصب‌کننده دانلود کامل شد: `ArtaveoDental-Setup-arm64-v0.12.2.exe`، منبع GitHub release v0.12.2، 10,810,091 بایت، SHA256 `7530034EB3893DE464F83C477C2E111D86A47275F75D4A99E8FAAE92A1A77EA7`، در `E:\Projects\Artaveo-TestData\backup-reinstall\dl\`. اجرا نشد.
- هم‌زمانی (دو توکن/دو پنجره روی یک کلینیک، API): ساخت هم‌زمان بیمار تکراری → فقط یکی ok؛ پرداخت هم‌زمان کل مانده از دو پنجره → فقط یکی ok و paid=net (اضافه‌پرداخت نشد). قفل خوش‌بینانه (version) با پارامتر ناقص امتحان شد و تست معتبر نشد.
- دیتابیس خراب (بایت‌های وسط فایل): `artaveo-dev-server` با panic بسته می‌شود (`open core: ... database disk image is malformed`)؛ این فقط dev-server است. Safe Startup Mode در اپ واقعی تست نشد.
- ابزار `computer-use` در این سشن نیست؛ پس نصب/حذف/نصب مجدد اپ واقعی، UI، safe startup، لاگ خطا با reference code در UI، update flow انجام نشد. هیچ فایلی در `C:\ProgramData` دست نخورد.

## جلسه‌ی سوم
- **حذف/نصب مجدد اپ واقعی:** `uninstall.exe /S` روی نصب واقعی توسط سیستم مجوز (auto mode) رد شد؛ دور نزدم. نیاز به انسان: حذف، نصب مجدد با `ArtaveoDental-Setup-arm64-v0.12.2.exe` (کپی در `E:\Projects\Artaveo-TestData\installers\`)، و مقایسه‌ی هش `C:\ProgramData\ArtaveoDental` با `_original-backup`. از `hooks.nsh` (خواندن کد، نه اجرا): حذف بی‌صدا/به‌روزرسانی هرگز داده را پاک نمی‌کند؛ حذف دستی دو بار تأیید می‌گیرد.
- **لاگ خطا/reference:** تأیید شد. خطای `attachments.file` با کد `JQGWZR` در `logs\artaveo.*.log` ثبت شد (method، origin، error). اما متن خطا در پاسخ انگلیسی/فنی است (BR-1).
