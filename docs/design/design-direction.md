# جهت طراحی Artaveo Dental (از v0.2.1)

**وضعیت:** پذیرفته‌شده — مبنای بازطراحی کامل v0.2.1 (OF-010) · جایگزین بخش ظاهری [ADR-24](../adr/ADR-24-design-tokens.md)
**هدف:** کاربر از دیدن و کار کردن با برنامه لذت ببرد؛ ظاهر در سطح نرم‌افزارهای تجاری درجه‌یک باشد، نه «کار می‌کند».

این سند سه بخش دارد: (۱) نقد صادقانه v0.2.0، (۲) الگوهایی که از نرم‌افزارهای مرجع برداشتیم و دلیل هرکدام، (۳) سیستم طراحی نهایی (Tokenها و کامپوننت‌ها) که کد `ui/src/styles.css` و `ui/src/ui/*` دقیقاً از آن پیروی می‌کند.

## ۳) سیستم طراحی نهایی

### ۳-۱ لایه‌ها (Glass)

```
پایه (Mica-like)        گرادیان + دو هاله رنگی کلینیک — ثابت، هرگز اسکرول نمی‌شود
└─ لایه فرمان           هدر و Sidebar — شیشه کم‌غلظت (۵۵٪) + blur ۲۴px + saturate ۱۸۰٪
   └─ لایه محتوا        کارت‌ها — شیشه غلیظ (۷۲٪ روشن / ۶۶٪ تیره) + حاشیه ۱px روشن + هایلایت داخلی بالا
      └─ لایه گذرا      منو، Popover، Dialog، Toast — شیشه بسیار غلیظ (۸۸٪) + blur ۳۰px + سایه عمیق
```

* خوانایی مقدم بر افکت: هیچ متنی مستقیم روی هاله رنگی نمی‌نشیند؛ کنتراست با بدترین حالت پس‌زمینه زیر شیشه محاسبه شده.
* **حالت کارایی** (`data-perf="reduced"`): پایه = رنگ ثابت، همه سطوح = مات (`--surface-*` opaque)، `backdrop-filter: none`، سایه‌ها یک‌لایه و کوچک. پیش‌فرض از `prefers-reduced-transparency`.
* `prefers-reduced-motion`: انیمیشن‌ها حذف، فقط تغییر رنگ آنی.

### ۳-۲ تایپوگرافی

* **Vazirmatn** (متغیر، ۱۰۰–۹۰۰) برای همه حروف عربی‌تبار (دری/پشتو)، **Inter** (متغیر) برای همه حروف لاتین — هر دو OFL و همراه برنامه. با `unicode-range` یک خانواده مجازی `Artaveo Sans` ساخته شده؛ در متن مختلط («بیمار: John Smith») هر خط با فونت درست خودش رندر می‌شود. Inter از نظر ارتفاع x و ضخامت با Vazirmatn (که لاتینش از خانواده گروتسک است) هماهنگ است.
* ؋ از Noto Sans Arabic (بدون تغییر، ADR-19).
* **monospace فقط** برای کلید بازیابی و کدها (`.mono`)؛ کادرها و سلول‌های LTR فقط جهت را عوض می‌کنند، فونت همان می‌ماند (OF-004).
* ارقام جدول‌ها و آمار: `font-variant-numeric: tabular-nums` (ستون‌ها روی هم می‌نشینند).

|---|---|---|---|
| `display` | 32 / 44 | 700 | عنوان صفحه خوش‌آمد و ورود |
| `title-lg` | 24 / 34 | 600 | عنوان صفحه (PageHeader) |
| `title` | 18 / 28 | 600 | عنوان کارت، Dialog |
| `subtitle` | 15 / 24 | 600 | عنوان بخش داخل کارت |

| `caption` | 12.5 / 20 | 400–500 | راهنمای کادر، سرستون جدول، Badge |

### ۳-۳ فاصله‌گذاری، اندازه‌ها، شعاع، سایه

* مقیاس فاصله مضرب ۴: `--space-1..12` = 4، 8، 12، 16، 20، 24، 32، 40، 48، 64.
* ارتفاع کنترل‌ها: کوچک ۳۲، معمولی ۴۰، بزرگ ۴۸ (ورود/خوش‌آمد). سطر جدول ۴۸. هدر ۶۴. Sidebar ۲۶۰.
* محتوای صفحه حداکثر ۱۱۲۰px عرض، حاشیه ۳۲px؛ فاصله بین کارت‌ها ۲۰px؛ پدینگ داخل کارت ۲۴px.
* شعاع: `--radius-sm` 6 (Checkbox، Badge کوچک) · `--radius-md` 8 (دکمه، کادر) · `--radius-lg` 12 (کارت، منو) · `--radius-xl` 16 (Dialog، پنل‌های ورود) · `--radius-full`.
* سایه‌ها چندلایه و نرم (یک سایه نزدیک تیز + یک سایه دور پخش): `--shadow-1` کارت، `--shadow-2` hover کارت/دکمه اصلی، `--shadow-3` منو/Popover، `--shadow-4` Dialog.
* حرکت: ۱۲۰ms (hover)، ۱۸۰ms (باز شدن منو)، ۲۶۰ms (Dialog)، منحنی `cubic-bezier(.2,0,0,1)` (Fluent decelerate).

### ۳-۴ رنگ

* **رنگ کاری برنامه = رنگ اصلی خود کلینیک** (2.1b)؛ پیش‌فرض teal `#0E7490`. چون کلینیک هر رنگی ممکن است انتخاب کند، `ui/src/lib/color.ts` از رنگ کلینیک برای هر تم نسخه‌های امن می‌سازد: رنگ دکمه، رنگ متن روی دکمه (سفید یا تیره، هرکدام کنتراست بیشتر)، رنگ لینک/متن تأکیدی که **حداقل ۴٫۵:۱** با سطح دارد (در صورت نیاز تیره/روشن می‌شود)، و پس‌زمینه‌های ملایم ۱۰–۱۶٪. تست واحد کنتراست AA را برای رنگ‌های بد (زرد روشن، سرمه‌ای تیره) تضمین می‌کند.

* خنثی‌ها از خانواده Slate (کمی سرد، مناسب محیط درمانی).

| **Table** | داخل Card؛ سرستون ۱۲٫۵px/۶۰۰ رنگ `--text-3` با پس‌زمینه ملایم؛ سطر ۴۸px؛ hover سطر؛ **تراز هر سلول = تراز سرستون، حتی وقتی محتوا LTR است** (OF-005: متن LTR داخل `<bdi>` جدا می‌شود، خود سلول جهت جدول را نگه می‌دارد)؛ ارقام tabular؛ حالت خالی و Skeleton بارگذاری. |
| **Badge / StatusDot** | Pill با پس‌زمینه ۱۲٪ و نقطه رنگی. |
| **Menu / Popover** | شیشه گذرا، ورود با محو + جابه‌جایی ۴px، آیتم‌ها ۳۶px با آیکن؛ Esc و کلیک بیرون می‌بندد. |
| **Dialog** | مرکز صفحه، شیشه گذرا، پس‌زمینه تیره ۴۰٪ + blur؛ هدر با عنوان و دکمه بستن؛ فوتر اکشن‌ها؛ فوکوس اول روی اولین کادر؛ Esc می‌بندد. |
| **Toast** | گوشه پایین (سمت انتهای خواندن)، شیشه گذرا، آیکن وضعیت، ۴ ثانیه؛ برای «ذخیره شد»/«ایجاد شد»/خطاهای عمومی. |
| **EmptyState / Skeleton / Spinner / ErrorState** | هر لیست هر چهار حالت را دارد: بارگذاری (Skeleton)، خالی (آیکن + جمله)، خطا (آیکن قرمز + پیام + «تلاش دوباره»)، داده. |
| **Avatar** | حرف اول نام در دایره با رنگ برند ملایم؛ لوگوی کلینیک یا حرف اول در مربع گرد. |

* **هویت کلینیک** (لوگوی بارگذاری‌شده یا حرف اول نام در نشان رنگی کلینیک + نام) در گوشه شروع هدر، برجسته (OF-011، 2.1b).
* Sidebar گروه‌بندی‌شده: «کلینیک» (اطلاعات کلینیک)، «مدیریت» (کاربران، پشتیبان‌گیری، گزارش رویدادها، تنظیمات)، «سیستم» (درباره برنامه). تغییر رمز و قفل در منوی کاربر.

### ۳-۷ RTL و متن مختلط

* همه فاصله‌ها و جهت‌ها با خصوصیات منطقی (`margin-inline-start`، `inset-inline-end`، `text-align: start`)؛ هیچ `left/right` ثابت جز جایی که عمداً LTR است.
* آیکن‌های جهت‌دار (فلش «بعدی/قبلی»، chevron) در RTL آینه می‌شوند؛ آیکن‌های غیرجهت‌دار (زنگوله، قفل) هرگز.
* هر قطعه LTR (نام کاربری، نسخه، مسیر فایل، حجم) با `<bdi>` جدا می‌شود تا ترتیب جمله فارسی به‌هم نریزد (OF-006).
* تاریخ و ساعت یک عبارت طبیعی: «۱۰ میزان ۱۴۰۵، ساعت ۱:۱۴ ق.ظ»؛ همه‌جا ۱۲ساعته: ق.ظ/ب.ظ (دری)، غ.م/غ.و (پشتو)، AM/PM (انگلیسی) — OF-007.

### ۳-۸ دسترس‌پذیری

* کنتراست متن حداقل WCAG AA (۴٫۵:۱؛ ۳:۱ برای متن ≥ ۱۸px پررنگ و آیکن‌ها/حاشیه کنترل‌ها).
* همه کارها با صفحه‌کلید: Tab منطقی، Esc برای بستن، `Ctrl+K`، حلقه فوکوس واضح.
* هیچ اطلاعاتی فقط با رنگ منتقل نمی‌شود (Badge همیشه متن یا آیکن دارد).
