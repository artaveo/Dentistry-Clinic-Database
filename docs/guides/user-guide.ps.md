# د کارونکي لارښود — Artaveo Dental

## یوه کاري ورځ
1. **ننوتل**: د کارونکي نوم او پټنوم. څو دقیقې بې‌کاره پاتې شئ، پاڼه تړل کیږي؛ په پټنوم یې پرانیزئ.
2. **نوی ناروغ**: «ناروغان ← نوی ناروغ». برنامه ورته نوم/تلیفون ته خبرداری ورکوي.
3. **وخت او منښه**: «وختونه» د مهال‌ویش لپاره؛ «منښه» د ناروغ د راتګ او انتظار لپاره.
4. **معاینه او د غاښونو چارټ**: د ناروغ په پوړ کې چارټ، کلینیکي یادښت، نسخه.
5. **د درملنې پلان**: خدمتونه پلان ته اضافه کړئ؛ وروسته له سرته رسولو نخښه یې کړئ.
6. **بل او تادیه**: صادر شوی بل نه بدلیږي (یوازې لغوه یا د اعتبار یادښت). تادیه، قسط، بیرته‌ورکول.
7. **رسید او چاپ**: A4، تودوخیز ۵۸/۸۰ ملي‌متره یا PDF.
8. **د ورځې صندوق تړل**: د ورځې په پای کې.
9. **بیک‌اپ**: پخپله کیږي؛ د «بیک‌اپ» په پاڼه کې حالت وګورئ.

## اوږده فورمې
هغه څه چې مو لیکلي د مسوده په توګه ساتل کیږي؛ که برنامه وتړل شي یا بریښنا ولاړه شي، بله ځل بیرته راوستل وړاندیز کیږي.
