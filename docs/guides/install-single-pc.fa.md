# نصب روی یک کامپیوتر (حالت پیش‌فرض)

## پیش‌نیاز
ویندوز ۱۰ یا ۱۱. نوع پردازنده را از **System Info** یا Settings ← System ← About ببینید: `x64` (اکثر کامپیوترها)، `x86` (۳۲ بیتی)، یا `ARM64`.

## مراحل
۱. از وب‌سایت Artaveo فایل مناسب را بگیرید: `ArtaveoDental-Setup-x64.exe` (یا `x86` / `arm64`). اگر کامپیوتر اینترنت ندارد، فایل `-offline.exe` را بردارید (WebView2 داخل آن است).
۲. فایل را اجرا کنید. ویندوز ممکن است هشدار **SmartScreen** بدهد (چون برنامه هنوز Code Signing ندارد):
   - روی **More info** بزنید، سپس **Run anyway**.
۳. **Next** و تا پایان. ویندوز مجوز مدیر (UAC) می‌خواهد؛ بپذیرید.
۴. برنامه را باز کنید. ویزارد راه‌اندازی: نام کلینیک، حساب مالک، رمز.
۵. **Recovery Key را همان لحظه چاپ کنید** و در جای امن (نه روی همین کامپیوتر) نگه دارید. بدون آن، بازیابی روی کامپیوتر جدید ممکن نیست.
۶. در صفحهٔ «پشتیبان‌گیری» یک فلش مورد اعتماد یا پوشهٔ ابر (Google Drive/OneDrive) را انتخاب کنید.
۷. در صفحهٔ «مجوز» کد فعال‌سازی را وارد کنید (یا درخواست آفلاین بدهید).

## به‌روزرسانی
کامپیوتر آنلاین: نوار بالای برنامه نسخهٔ جدید را پیشنهاد می‌دهد؛ **نصب نسخهٔ جدید** را بزنید. برنامه اول Backup می‌گیرد، بعد نصب می‌کند و دوباره باز می‌شود. دستی: نصب‌کنندهٔ جدید را روی قبلی اجرا کنید؛ اطلاعات حفظ می‌شود و Migration خودکار انجام می‌شود.

## تعمیر
همان نصب‌کنندهٔ همین نسخه را دوباره اجرا کنید؛ فایل‌های برنامه جایگزین می‌شوند و اطلاعات دست نمی‌خورد.

## حذف برنامه
Settings ← Apps ← Artaveo Dental ← Uninstall. **اطلاعات کلینیک پاک نمی‌شود** (در `C:\ProgramData\ArtaveoDental`). فقط اگر حذف را دستی انجام دهید و دوبار صریحاً «Yes» بزنید، اطلاعات هم پاک می‌شود.
