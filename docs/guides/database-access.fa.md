# دسترسی مستقیم به دیتابیس (SQL / SQLite)

دیتابیس رمز شده است (SQLCipher)؛ ابزار معمولی SQLite آن را نمی‌خواند. ابزار `artaveo-dump` یک **پشتیبان** را با **Recovery Key** باز می‌کند و خروجی بدون رمز می‌دهد. فایل `artaveo-dump-<معماری>.exe` کنار نصب‌کننده‌ها در Release است؛ چیز دیگری نصب نمی‌شود.

## اجرا (PowerShell)

```powershell
$env:ARTAVEO_RECOVERY_KEY = "کلید بازیابی چاپ‌شده"
.\artaveo-dump-x64.exe --backup "C:\ProgramData\ArtaveoDental\backups\artaveo-20261110-190000-daily.db" --out dump.sql
```

- `--out dump.sql`: اسکریپت SQL کامل (جدول‌ها، ردیف‌ها، ایندکس‌ها، view و trigger).
- `--sqlite plain.sqlite`: فایل SQLite بدون رمز؛ با DB Browser for SQLite یا هر ابزار SQLite باز می‌شود.
- `--force`: جایگزینی فایل خروجی موجود (پیش‌فرض: هرگز رونویسی نمی‌کند).
- کنار فایل پشتیبان باید `.rkey` همنام آن باشد (همراه هر پشتیبان ساخته می‌شود).

## نکته‌ها
- **همیشه روی پشتیبان کار کنید، نه `clinic.db`.** ابزار فایل زنده را رد می‌کند.
- جدول‌های جست‌وجوی FTS در خروجی نیستند؛ برنامه آن‌ها را بازسازی می‌کند.
- پیوست‌ها (عکس، اسناد) فایل‌های جدا در `attachments\` هستند و در خروجی نیستند.
- **خروجی همهٔ اطلاعات بیماران را بدون رمز دارد.** در جای امن نگه دارید و بعد از کار پاک کنید.
