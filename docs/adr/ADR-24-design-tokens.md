# ADR-24 — نشانه‌های طراحی و حالت نمایش

**وضعیت:** پذیرفته‌شده · **شواهد:** فاز ۲ (Design System, Application Shell, Localization & Clinic Setup)

## زمینه

فاز ۱ یک اسکلت حداقلی از CSS ساخت (`ui/src/styles.css`، با عنوان صریح «فقط اسکلت فاز ۱؛ سیستم طراحی واقعی در فاز ۲ است») و حالت تیره فقط از طریق `prefers-color-scheme` سیستم‌عامل بود، بدون کلید دستی. فاز ۲ باید نشانه‌های طراحی واقعی، هر دو حالت روشن/تیره (با انتخاب دستی)، و «حالت کارایی» برای کامپیوترهای ضعیف را اضافه کند.

## تصمیم

* نشانه‌ها (Design Tokens) به‌صورت **CSS Custom Properties** روی `:root` تعریف می‌شوند: رنگ‌های معنایی (`--bg`, `--surface`, `--text`, `--accent`, `--ok`, `--bad`, …)، مقیاس فاصله (`--sp-1`…`--sp-7`)، شعاع گردی (`--radius-*`)، سایه (`--shadow-*`) و اندازه فونت (`--font-size-*`). هیچ کتابخانه CSS یا کامپوننت جدیدی (Tailwind، MUI، …) اضافه نشد؛ با فلسفه کم‌وابستگی کد فعلی هماهنگ است.
* **حالت نمایش** سه‌گزینه‌ای است: `light` / `dark` / `system`. انتخاب در `data-theme` روی `<html>` ذخیره و در `localStorage` نگه‌داری می‌شود؛ `system` یعنی بدون مقدار این ویژگی و پیروی از `prefers-color-scheme`. انتخاب اول‌بار (در ویزارد راه‌اندازی) به‌عنوان تنظیم کلینیک هم ذخیره می‌شود (`clinic.theme`)، ولی هر کامپیوتر می‌تواند بعداً حالت خودش را جدا عوض کند (ترجیح کاربر، نه قفل‌شده به کلینیک).
* **حالت کارایی** (`data-perf="full" | "reduced"`) جلوه‌های سنگین (`backdrop-filter`، سایه‌های بزرگ) را در حالت `reduced` غیرفعال می‌کند؛ پیش‌فرض از `prefers-reduced-transparency` و قابل تغییر دستی.
* کامپوننت‌های نو (Sidebar، TopBar، Dialog، Command Palette، Stepper، Segmented Control، Color Swatch) کلاس‌های CSS ساده‌اند، نه کتابخانه کامپوننت؛ صفحات فاز ۱ (Users، Audit، Backup، Settings، Login، Password) بدون تغییر کد با همان کلاس‌های قبلی (`card`, `row`, `button.primary`, …) روی نشانه‌های تازه رندر می‌شوند.

## پیامدها

* افزودن یک کامپوننت یا صفحه جدید فقط باید از متغیرهای موجود استفاده کند؛ رنگ/فاصله/شعاع hex یا px مستقیم داخل کد جدید نوشته نشود.
* تغییر حالت نمایش یک انتخاب شخصی/دستگاهی باقی می‌ماند؛ به‌روزرسانی `clinic.theme` (از صفحه اطلاعات کلینیک) فقط پیش‌فرض آینده را عوض می‌کند، کامپیوترهایی که از قبل حالت خودشان را انتخاب کرده‌اند تغییر نمی‌کنند.

## به‌روزرسانی v0.2.1 — بازطراحی کامل (OF-010)
ظاهر v0.2.0 توسط مالک محصول رد شد. از v0.2.1 مرجع ظاهر [docs/design/design-direction.md](../design/design-direction.md) است و این ADR فقط سازوکار را نگه می‌دارد:
* Tokenها همچنان CSS Custom Properties روی `:root` هستند ولی بازنویسی شدند: مقیاس تایپ (`--text-*`)، فاصله مضرب ۴ (`--space-1…10`)، شعاع ۶/۸/۱۲/۱۶، سایه‌های چندلایه `--shadow-1…4`، لایه‌های شیشه (`--glass-nav/card/overlay`) و رنگ‌های معنایی با کنتراست WCAG AA.
* **رنگ کاری = رنگ اصلی کلینیک**؛ `ui/src/lib/color.ts` برای هر تم نسخه‌ای می‌سازد که کنتراست ۴٫۵:۱ را تضمین می‌کند (تست واحد با رنگ‌های بد).
* کلاس‌های قدیمی فاز ۱ حذف شدند؛ همه صفحه‌ها از کامپوننت‌های `ui/src/ui/*` (Button، Field، Select، TimePicker12، Card، Table، Dialog، Popover، Toast، EmptyState…) استفاده می‌کنند. تنها وابستگی تازه **lucide-react** (آیکن، ISC) است.
* حالت کارایی (`data-perf="reduced"`) همه `backdrop-filter`ها را خاموش و سطوح را مات می‌کند؛ همان چیدمان و همان کنتراست.
