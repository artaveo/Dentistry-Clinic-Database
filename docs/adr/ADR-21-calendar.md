# ADR-21 — پیاده‌سازی تقویم شمسی

**وضعیت:** پذیرفته‌شده · **شواهد:** [Spike 5](../spikes/05-shamsi-calendar.md)

## تصمیم
* **Core (Rust):** ماژول `shamsi` خودمان (الگوریتم breaks/Borkowski، بدون وابستگی) — مرجع واحد برای گزارش‌ها، دوره‌های ماهانه/سالانه و شماره‌گذاری سالانه اسناد.
* **UI:** `@internationalized/date` (`PersianCalendar`) و `DatePicker` از React Aria — روزبه‌روز با Core یکسان (۷۳٬۴۱۴ روز تست‌شده).
* نام ماه‌ها و روزها از **جدول خودمان** (دری: حمل…حوت، پشتو: وری…کب، انگلیسی: Hamal…Hut)؛ ICU فقط برای ارقام و جداکننده‌ها.
* هفته از شنبه؛ ذخیره همیشه UTC/میلادی (ADR-07/08 بدون تغییر).
* ارقام (ADR-09): نرمال‌سازی ورودی با `digits::to_latin`، کلید جستجوی تلفن با `digits::phone_search_key`.

## به‌روزرسانی فاز ۲

* ماژول `shamsi` از `spikes/shamsi` به **`core/src/calendar.rs`** (+ `core/src/calendar/digits.rs`) منتقل شد — دیگر فقط یک نمونه آزمایشی نیست، بخش واقعی محصول است، همراه با همان تست‌های جامع (roundtrip ۱۳۰۰ تا ۱۵۰۰، Nowruzهای شناخته‌شده، سال‌های کبیسه).
* کلینیک در ویزارد راه‌اندازی بین تقویم **هجری شمسی** (پیش‌فرض) و **میلادی** یکی را انتخاب می‌کند (`clinic.calendar_system`)؛ ذخیره همیشه میلادی/UTC می‌ماند، فقط نمایش تغییر می‌کند.
* سمت UI هنوز از `@internationalized/date`/React Aria استفاده نمی‌کند؛ `ui/src/lib/dates.ts` با همان جدول ماه‌های Core (به‌صورت جدا نگه‌داری‌شده) و `Intl.DateTimeFormat` نمایش می‌دهد. این تصمیم آگاهانه است: فاز ۲ فقط به **نمایش** تاریخ نیاز دارد، نه **ورودی/انتخاب** تاریخ (اولین نیاز واقعی یک Date Picker، نوبت‌دهی در فاز ۴ است). پذیرش `@internationalized/date` به همان فاز موکول شد تا وابستگی زودهنگام و بدون مصرف واقعی اضافه نشود.

## به‌روزرسانی فاز ۴

* نوبت‌دهی اولین نیاز واقعی به **انتخاب** تاریخ بود؛ بنابراین `@internationalized/date` همین‌جا اضافه شد، همان‌طور که ADR پیش‌بینی کرده بود. `ui/src/lib/calendar.ts` (روز، هفته، ماه، تبدیل شمسی/میلادی، هفته از شنبه) و کامپوننت `DateField` (روز، نام ماه و سال در تقویم کلینیک) روی آن ساخته شده‌اند؛ تاریخ هرگز در تقویم اشتباه تایپ نمی‌شود و روز ناموجود (مثل ۳۱ میزان) فرستاده نمی‌شود. به‌جای React Aria `DatePicker` از سه انتخاب‌گر ساده استفاده شد تا فرم نوبت سریع بماند.
* تست `calendar.test.ts` رفت‌وبرگشت شمسی ↔ میلادی را روی چند هزار روز و ساعت کابل را (نه ساعت کامپیوتر) بررسی می‌کند.
* در Core، تاریخ نوبت همیشه تاریخ **محلی کلینیک** (ISO میلادی) و لحظه آغاز/پایان UTC است (ADR-07)؛ ماه شمسی فقط در UI بریده و نام‌گذاری می‌شود.
