# راهنمای بازبینی متن‌های پشتو

این راهنما برای یک **گوینده بومی پشتو** است و نیازی به دانش فنی یا باز کردن کد ندارد.

## چه چیزی را بازبینی کنم؟

فایل [`pashto-review.md`](pashto-review.md) تمام متن‌های رابط برنامه (دکمه‌ها، عنوان‌ها، پیام‌ها) را در یک جدول نشان می‌دهد:

| ستون | توضیح |
|---|---|
| کلید | فقط برای توسعه‌دهنده است؛ به آن کاری نداشته باشید. |
| English | متن انگلیسی همان مورد، برای این‌که منظور دقیق را بفهمید. |
| دری | متن دری — توسط مالک محصول تأیید شده و **نباید تغییر کند**. |
| پښتو | متن پشتویی که باید بازبینی شود. |
| یادداشت بازبینی | این ستون برای شماست. |

برای هر سطر بررسی کنید:

1. **املا و دستور زبان** درست باشد.
2. ترجمه **طبیعی و روان** باشد (نه ترجمه کلمه‌به‌کلمه از دری/انگلیسی).
3. یک واژه برای یک مفهوم در همه‌جا **یکسان** استفاده شده باشد (مثلاً همیشه یک واژه برای «ذخیره» یا «لغو»).
4. علائم نگارشی (نقطه، ویرگول «،») با جهت راست‌به‌چپ درست نمایش داده شوند.

## چطور نظرم را ثبت کنم؟

نیازی به ویرایش کد یا فایل JSON نیست. دو راه ساده دارید:

* **اگر با Git/GitHub راحت هستید:** مستقیم ستون «پښتو» را در همین فایل اصلاح کنید و ستون «یادداشت بازبینی» را با توضیح کوتاه (یا فقط «✓ تأیید شد») پر کنید.
* **اگر نه:** فایل را دانلود یا پرینت کنید، روی آن یادداشت/اصلاح بنویسید و برای تیم توسعه برگردانید؛ تیم تغییرات را در فایل‌های برنامه اعمال می‌کند.

## نکته فنی (فقط برای توسعه‌دهنده)

این فایل از `ui/src/i18n/{fa,ps,en}.json` با `node ui/scripts/export-pashto-review.mjs` ساخته می‌شود. وقتی گوینده بومی اصلاحات پشتو را برگرداند، آن‌ها را در `ui/src/i18n/ps.json` اعمال کنید (نه در این فایل)، سپس اسکریپت را دوباره اجرا کنید تا این جدول به‌روز شود.

این فایل مکمل بازبینی متن‌های پشتوی **ولایت‌ها و ولسوالی‌ها** است که در [core/seeds/README.md](../../core/seeds/README.md) پیگیری می‌شود؛ آن یکی داده جغرافیایی است، این یکی متن‌های خود رابط برنامه.
