**Artaveo Dental 0.1.0 — Phase 1 (Engineering Foundation)**

نسخه آزمایشی برای تست دستی مالک محصول. هنوز برای استفاده واقعی در کلینیک نیست.

### کدام فایل را دانلود کنم؟

| کامپیوتر شما | فایل |
|---|---|
| ویندوز ۶۴ بیتی معمولی (Intel/AMD) — بیشتر کامپیوترها | `ArtaveoDental-Setup-x64.exe` |
| ویندوز ۳۲ بیتی (کامپیوترهای قدیمی) | `ArtaveoDental-Setup-x86.exe` |
| ویندوز روی پردازنده ARM (مثل Surface Pro X / Snapdragon) | `ArtaveoDental-Setup-arm64.exe` |

نسخه‌های `-offline` برای کامپیوترهای **بدون اینترنت** هستند (بزرگ‌ترند چون WebView2 را همراه دارند).
راهنمای کامل تست: `docs/testing/phase-1-manual-test.md` در مخزن.

### آنچه در این نسخه هست
- راه‌اندازی اولیه کلینیک و حساب مالک، نمایش **کلید بازیابی** (Recovery Key)
- دیتابیس محلی **رمزنگاری‌شده** (SQLCipher) با کلید محافظت‌شده توسط ویندوز (DPAPI)
- ورود، قفل خودکار صفحه، قفل دستی، تغییر رمز، بازیابی رمز مالک با Recovery Key
- کاربران و نقش‌ها (مالک، مدیر، پذیرش، داکتر، حسابدار، دستیار) با دسترسی‌های جداگانه
- گزارش رویدادها (Audit Log) فقط-خواندنی
- پشتیبان‌گیری محلی دستی و روزانه خودکار
- صفحه «درباره برنامه» (نسخه، نوع پردازنده، وضعیت رمزنگاری، آخرین پشتیبان)
- رابط دری، پشتو و انگلیسی

نصب‌کننده امضای دیجیتال ندارد؛ ویندوز هشدار SmartScreen نشان می‌دهد (`More info` → `Run anyway`).
