# Spike 5 — Shamsi Calendar

**سؤال:** کتابخانه تقویم شمسی برای Date Picker، نمایش و گزارش‌ها کدام است؟
**نتیجه:** ✅ **تصمیم:** ADR-21.

## آنچه ساخته شد

* `spikes/shamsi` — ماژول Rust بدون وابستگی (الگوریتم Borkowski/«breaks»، همان jalaali-js): تبدیل دوطرفه، سال کبیسه، طول ماه، روز هفته (شنبه = ۰)، نام ماه‌های **افغانی** (دری، پشتو، انگلیسی)، و `digits` برای ADR-09 (تبدیل ارقام فارسی/عربی به لاتین، کلید جستجوی تلفن).
* تست کامل رفت‌وبرگشت **همه روزهای ۱۳۰۰ تا ۱۵۰۰ شمسی**، نوروزهای شناخته‌شده، کبیسه‌های ۱۳۹۱/۱۳۹۵/۱۳۹۹/۱۴۰۳/۱۴۰۸.
* `print-lab/scripts/shamsi-crosscheck.mjs` — مقایسه روزبه‌روز ۷۳٬۴۱۴ روز (۱۹۲۵–۲۱۲۵ میلادی):

```text
DIFF  ICU / Intl (WebView2): 366 mismatching days  (فقط 2124-03-20 تا 2125 — سال ۱۵۰۲/۱۵۰۳)
SAME  jalaali-js: 0
SAME  date-fns-jalali: 0
SAME  @internationalized/date: 0
```

## تصمیم

| لایه | انتخاب | دلیل |
|---|---|---|
| Rust Core (گزارش‌ها، دوره‌های ماهانه، شماره رسید سالانه) | `shamsi` crate خودمان | بدون وابستگی، تست‌شده، مرجع واحد |
| UI — Date Picker | `@internationalized/date` + React Aria `DatePicker` با `PersianCalendar` | ۱۰۰٪ هم‌خوان با Core، RTL و دسترس‌پذیری آماده |
| UI — نمایش | `Intl` فقط برای اعداد تقویم + جدول نام ماه خودمان | نام ماه‌های ICU برای `en` ایرانی است |

## یافته‌ها

1. افغانستان نام‌های برجی (حمل، ثور، … حوت / وری، غویی، … کب) استفاده می‌کند؛ بیشتر کتابخانه‌ها پیش‌فرض ایرانی (فروردین…) دارند.
2. ICU در سال ۲۱۲۴ میلادی با الگوریتم مرجع اختلاف دارد ← نمایش هم از Core/`@internationalized/date` گرفته شود، نه مستقیم از ICU، تا در هیچ تاریخی UI و Core متفاوت نشوند.
3. هفته از **شنبه** شروع می‌شود؛ جمعه تعطیل (برای تقویم نوبت‌دهی فاز ۴).
