# Artaveo brand assets

Place the official Artaveo logo files here (provided by the product owner):

- `logo.svg` — full logo, vector (preferred source for everything)
- `logo-1024.png` — full logo, 1024px, transparent background
- `icon.svg` / `icon-1024.png` — square mark only (app icon, installer, taskbar)
- `logo-mono.svg` — single-colour version for black-and-white printing

All app icons (`.ico`, Tauri icon set, installer images) are generated from these files.
See roadmap section 2.1b for where the Artaveo brand vs. the clinic brand appears.
